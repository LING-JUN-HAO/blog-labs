# CSS Subgrid 實驗

文章的一個段落對應一個頁面，全部是純 HTML、CSS，不需要安裝任何套件。

| 頁面 | 段落 |
| --- | --- |
| `basic-subgrid.html` | 巢狀 Grid 為什麼對不齊？ |
| `cards.html` | 三張內容長度不同的卡片 |
| `flexbox.html` | Flexbox 可以讓連結區域對齊 |
| `nested-grid.html` | 一般巢狀 Grid 仍然各算各的 |
| `subgrid.html` | Subgrid 讓卡片共用父層軌道 |
| `rows.html` | 每一排的卡片會各自對齊 |
| `fallback.html` | 用 `@supports` 保留 Flexbox |

`style.css` 是每頁共用的卡片樣式，各段落要比較的 CSS 寫在各頁的 `<style>` 裡。
標題、中間內容、連結區域分別上了不同底色，錯開時比較容易看出來。

## 跑起來

直接用瀏覽器打開 `index.html` 就可以。

卡片比較頁下方會量出各卡片的標題高度、中間內容與連結區域的起點（相對於卡片頂端），並判斷同一排的卡片有沒有對齊。

## 每頁看什麼

### 巢狀 Grid 為什麼對不齊？

父層有四欄，其中兩個標籤欄由內容決定寬度，另外兩欄分別占 `2fr` 與 `1fr`。一般巢狀 Grid 會把自己的寬度均分成兩欄，中間的分隔線不會對齊父層格線；改用 `grid-template-columns: subgrid` 後，兩個項目各跨兩條父層軌道，內容或可用寬度改變時仍會沿用同一組格線。

### 三張內容長度不同的卡片

只有外層 Grid。三張卡片等高，但內容擠在上方：連結區域起點是 145px、199px、145px。

### Flexbox 可以讓連結區域對齊

連結區域起點都是 199px，但第二張卡片的標題換成兩行（90px，另外兩張是 61px），中間內容起點變成 91px，另外兩張是 62px。

### 一般巢狀 Grid 仍然各算各的

量測結果和 Flexbox 一模一樣：每張卡片的 `auto 1fr auto` 各自計算。

### Subgrid 讓卡片共用父層軌道

三張卡片的標題都是 90px，中間內容都從 91px 開始，連結區域都從 199px 開始。
短標題的卡片會多出空白，因為標題列被第二張卡片撐高了。

### 每一排的卡片會各自對齊

六張卡片。寬度大於 900px 是三欄，900px 以下兩欄，560px 以下一欄。

- 三欄時，第一排的進階方案標題換成兩行（90px），只撐高第一排的標題列，第二排的標題仍是 61px。
- 第二排的「教育方案」中間內容很長，只會撐高第二排的中間內容列，第一排不受影響。
- 縮成兩欄，變成每兩張一組；縮成一欄，每張卡片自成一排，沒有跨卡片對齊。
- 量測結果會標出共有幾排、每排各自比較。

### 用 @supports 保留 Flexbox

頁面上會顯示目前的瀏覽器支不支援 Subgrid。支援時結果和 `subgrid.html` 相同。
想看不支援時的樣子，可以在 DevTools 把 `@supports` 區塊裡的規則取消勾選，結果會變回和 `flexbox.html` 相同。
