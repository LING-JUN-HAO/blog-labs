巢狀 Grid 為什麼對不齊？

父層的標籤欄由內容決定寬度，另外兩欄分別占 2fr 與 1fr。比較一般巢狀 Grid 與 Subgrid，可以看到子層是否真正沿用父層軌道。

使用 Subgrid

CSS

.layout {
  display: grid;
  grid-template-columns:
    max-content 2fr max-content 1fr;
  gap: 1rem;
}

/* 一般巢狀 Grid：重新建立軌道 */
.nested {
  display: grid;
  grid-column: 1 / -1;
  grid-template-columns: repeat(2, 1fr);
  gap: 1rem;
}

/* Subgrid：沿用父層軌道 */
.nested {
  display: grid;
  grid-column: 1 / -1;
  grid-template-columns: subgrid;
}

.nested > * {
  grid-column: span 2;
}
