用 @supports 保留 Flexbox

支援 Subgrid 時，標題、中間內容與連結區域都會對齊；不支援時退回 Flexbox，至少連結區域仍貼齊底部。

這個瀏覽器 Subgrid。

CSS

.card {
  display: flex;
  flex-direction: column;
}

.card__content {
  flex: 1;
}

@supports (
  grid-template-rows: subgrid
) {
  .card {
    display: grid;
    grid-row: span 3;
    grid-template-rows: subgrid;
    gap: 0;
  }
}
